Panel 2 — The 17 Orthogonality Conditions

For r to be root18, it must satisfy:

rT · H · ri = 0    for i = 1, 2, ..., 17

Equivalently, define the row vector wi = (HT ri)T. Then:

W · r = 0    where W is the 17×4 matrix with rows w1,...,w17

What This System Means

17 equations, 4 unknowns. The rank of W determines the solution space:

rank(W) = 0 → all of Z4 works → trivially open
rank(W) = 1 → 3D hyperplane solution → very open
rank(W) = 2 → 2D plane solution → open
rank(W) = 3 → 1D line solution → narrow corridor
rank(W) = 4 → only r = 0 → BLOCKED (no root18)

Where Are the 17 Root Vectors?

The 17 prior roots live in the ambient 22-dimensional Stoicheion lattice. Their 4D coordinates (in the F4 basis) are derived through:

22D ambient → index-64 basis B (RQT-198) → 15 roots in 21D (RQT-201..215)
  → saturated 6D kernel (RQT-216/541) → root16 (RQT-544)
    → root17 (RQT-241) → saturated 4D kernel K (RQT-242)
      → F4 = KT · G · K,  H4 = Wall restriction to 4D

The 4D coordinates of the 17 prior roots are expected as external input (--prior-roots-json in rqt362). They have NOT been extracted as a standalone JSON file in the quanta repository. The full derivation chain lives in DavidWise01/stoicheion.

  • The entire 4-root block R=[r18,r19,r20,r21] must have det(R)=±1 (RQT-376)

Critical Implication for the 17 Prior Roots

The 17 prior roots project to 4D via the saturated kernel K. In 4D, their Wall constraints wi = HT ri form a 17×4 matrix W. Since the kernel ladder drops by exactly 1 per root starting at root18, and root18 EXISTS as a candidate (RQT-386), the rank of W restricted to the prior 17 roots must be:

rank(Wprior) ≤ 3    (otherwise root18 candidate couldn't exist)

If rank = 0: prior roots impose NO constraint in 4D → all 4 freedoms remain
If rank = 1: prior roots eat 1 freedom → 3 remain for roots 18-21
If rank = 2: prior roots eat 2 freedoms → 2 remain → need rank-2 four-root block
If rank = 3: prior roots eat 3 freedoms → 1 remains → root18 is on a LINE

KEY QUESTION: What is rank(Wprior)? This determines whether root18 is essentially forced (rank 3) or has significant freedom (rank ≤ 2). CANNOT be answered without the 17 root vectors.

Imagine you're building a tower of blocks. You've already stacked 17 blocks, and now you need to put on block number 18.

But block 18 can't just be ANY block. It has to fit perfectly — it needs to be "smooth" against EVERY block below it. That means 17 different "smooth checks."

The puzzle is: we have a block that's the right SIZE (norm = −2 ✓) and the right COLOR (parity = 0111 ✓) and the right SHAPE (first-stage gate ✓). But we haven't tried stacking it yet!

The 17 blocks below are in a different room (the stoicheion repo). We need someone to bring them over so we can test: does block 18 sit smooth against all 17?

Also, once block 18 is placed, blocks 19, 20, 21 each have LESS room. Block 21 has NO choice at all — it's the only one that fits!

The whole tower is 21 blocks tall, and we're at block 18. Three blocks to go. This is where everything converges.
