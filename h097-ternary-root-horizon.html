Panel 5 · The Hidden Key — Conditional Escape Velocity (RQT-381)

RQT-381 proves: IF a primitive null vector u exists on certain ternary slope planes with gcd(F4·u)=1, THEN an explicit arithmetic recipe produces r with rTF4r = -2. This is the escape velocity condition.

Given: u ∈ Z4, primitive, uTF4u = 0, gcd(F4·u) = 1
Construct: z via extended Euclid with uTF4z = 1
Choose: v₀ ∈ {0,1,2,3}4 with uTF4v₀ ≡ 1 mod 4
Adjust: v = v₀ + 4·((1-n)/4)·z so uTF4v = 1
Result: r = (1 + q(v))·u − v
Proof: q(r) = (1+q(v))²·q(u) + q(v) − (1+q(v))·(uTF4v)
       = 0 + q(v) − (1+q(v)) = -1
Therefore: rTF4r = 2·q(r) = -2 ✓

TODDLER VERSION — The Ternary Root Horizon

Imagine you have a special grid with numbers, like a puzzle. You need to find a magic combination of four numbers that, when you plug them into the grid's formula, gives you exactly -2.

People have been looking for this combination for a long time. They've written 298 research papers and 247 computer programs trying to find it.

They know the magic combination can only come in three flavors (like three doors). They've proven that behind each door, the combination exists in a special "close-up" math world (like looking through a magnifying glass). But when you zoom out to see ALL the numbers, nobody has found the combination yet.

They also found a secret recipe: IF you can find a different magic number first (a "null vector"), the recipe will automatically build the combination you want. But nobody has found that first magic number either.

It's like knowing there's treasure behind one of three doors, having a key that works in the lock when you test it really close up, but not being able to actually open the door and get the treasure. The treasure is trapped behind a horizon — you can prove it's there locally, but you can't reach it globally.
