Panel 3 — The Lock: Where the Box Wraps

A box with 16 cells has addresses 0 through 15. That's d₁⁴ addresses.

Address 16 doesn't exist inside the box. In a flat box, it's outside. But with periodic boundary conditions:

  Address 0  → inside the box
  Address 1  → inside
  ...
  Address 15 → inside (last cell)
  Address 16 → WRAPS to 0. The box is now a toroid.
  Address 17 → the first address AFTER the wrap

The lock at 17 = d₁⁴ + 1 is where the flat box can't go. It's the boundary condition. The place where the topology changes from box to toroid.

W − C = d₂ − 1 = 17 from the master equation. The lock was always the wrap point.
