Panel 3 — THE CRITICAL FINDING: Wall Prefix is Vacuous

THE KERNEL ARGUMENT
===================

Given: T17 (21×17 matrix of roots), H21 (21×21 Wall form)

Define: A17 = T17^T · H21^T    (17×21 matrix, rank 17)

The 4D residual kernel N4 is:  null(A17)   (dimension 4)

By definition:   A17 · N4 = 0
                 T17^T · H21^T · N4 = 0
                 (H21^T · N4)^T · T17 = 0
                 N4^T · H21 · T17 = 0        ← THIS IS THE KEY

For any root18 = N4 · x (a 4D vector lifted to 21D):
   root18^T · H21 · root_i = x^T · N4^T · H21 · root_i
                            = x^T · (column i of N4^T · H21 · T17)
                            = x^T · 0
                            = 0

THEREFORE: Wall prefix orthogonality is AUTOMATICALLY SATISFIED
           for ANY vector in the 4D residual subspace.
           It is not a constraint. It is a tautology.

VERIFIED COMPUTATIONALLY: N4_sat^T · H21 · T17 = 0 (all 68 entries zero).

Consequence: The root18 candidate from RQT-386 (norm -2, parity 0111, H-self 1) does NOT need a separate Wall prefix check. If it lives in the 4D residual subspace — which it does by construction — it automatically has zero Wall pairing with all 17 prior roots.

What remains: The 21-reflection word factorization (can the product of 21 reflections including root18 equal the original isometry X?) and roots 19, 20, 21.

🧒 Explain Like I'm Little

Imagine you have a BIG box of 22 crayons. Someone already used 17 of them to draw 17 special lines on a piece of paper. Each line follows strict rules — it has to be exactly the right length (norm = -2) and it has to stand up straight on its own (self-pairing = 1).

Now you want to draw an 18th line. The old rule said: "Your new line has to be perfectly straight compared to ALL 17 old lines" (that's the Wall prefix check). That sounds really hard — 17 things to check!

But here's the trick: when we looked carefully at WHERE the 18th line lives (in a little 4-dimensional corner that's left over after the first 17 lines took up their space), we found that any line drawn in that corner is AUTOMATICALLY straight compared to all 17 old lines. It's like a playground where, if you stay inside the sandbox, you can't possibly bump into anyone on the swings. The sandbox and the swings don't overlap at all.

So the hard part (checking 17 things) turned out to be no work at all. It just happens for free! 🎉
