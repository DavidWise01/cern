Panel 4 — The Quadratic Bound

  Q3p(16k, 9k, 1) = Ak² + 2Bk + C

  A = Q3p(16, 9, 0)   = + (326 digits)  ← the c=0 escape value
  B = 16·Q02 + 9·Q12  = + (366 digits)  ← coupling terms
  C = Q22              = − (408 digits)  ← the torroid anchor

  This quadratic in k crosses zero when:
    k₊ = (−B + √(B²−AC)) / A

  B² = 732 digits
  AC = −733 digits (A positive × C negative = negative)
  B²−AC = +733 digits (always positive: B² + |AC|)

  √disc ≈ 10³⁶⁷
  k₊ ≈ (10³⁶⁶ + 10³⁶⁷) / 10³²⁶ ≈ 10⁴¹

  THE c=1 ESCAPE EXISTS AT WORD LENGTH ≈ 10⁴²
