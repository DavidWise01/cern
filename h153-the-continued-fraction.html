H153 — The Continued Fraction

Engine: Rust BigInt (num-bigint 0.5.1) · 400-digit precision · Bridge Arc

Panel 1 — What We Asked

From H152: the null cone ratio n₊ ≈ 1.771 governs word length for w=0 roots. Compute its continued fraction expansion. Each convergent p_k/q_k is the BEST rational approximation with denominator ≤ q_k. The CF determines how efficiently the integer lattice can approximate the irrational null-cone direction.

But first: CAN the binary form Q00·x² + 2Q01·xy + Q11·y² represent zero over the integers? This requires the discriminant 4R01 to be a perfect square.

THEOREM: The binary form Q00·x² + 2Q01·xy + Q11·y² has discriminant 4R01 which is NOT a perfect square. Therefore this form does NOT represent zero over the integers.

PROOF: R01 = isqrt(R01)² + r where r is a 326-digit nonzero residual. Since r > 0, R01 is not a perfect square. Therefore 4R01 = 4(s² + r) = (2s)² + 4r is not a perfect square. A binary quadratic form ax² + bxy + cy² represents zero over Z only if its discriminant b² − 4ac is a perfect square. Here discriminant = (2Q01)² − 4Q00·Q11 = 4(Q01² − Q00Q11) = 4R01. ∎

CONSEQUENCE: No lattice point (a, b, 0) lies on Q3p = 0. ALL roots of the frozen lattice on the null cone must have c ≥ 1.

Panel 5 — The Repulsion Mechanism

Why Q3p stays constant at ~325d:

Q3p(p_k, q_k, 0) = Q00 · q_k² · (p_k/q_k − n₊)(p_k/q_k − n₋)

The error |p_k/q_k − n₊| shrinks like 1/(q_k · q_{k+1}) by CF theory. But Q3p has a q_k² factor, so:

|Q3p| ≈ |Q00| · q_k² · (1/(q_k·q_{k+1})) · |n₊ − n₋|
       = |Q00| · (q_k/q_{k+1}) · 0.0146...
       ≈ 10³²⁸ · (1/a_{k+1}) · 0.0146
       ≈ 10³²⁶ / a_{k+1}

The q_k² growth in the quadratic form EXACTLY cancels the 1/q_k² convergence of the CF. The result is a CONSTANT residual of order 10³²⁵-10³²⁶ regardless of how many generator steps you take. The binary form is an elastic wall.

Sign alternation: Convergents k=0,1,2 all negative (all outside the interval [n₊, n₋]). From k=3 onward, odd convergents land BETWEEN n₊ and n₋ (positive), even convergents land BELOW n₊ (negative). The null cone is BRACKETED but never reached.

Panel 6 — Correction to H150

H150 claimed: 18 roots have w = 0 (the "w=0 family").

H153 proves: NO integer point (a, b, 0) lies on the null cone Q3p = 0.

Resolution: The "w ≈ 0" classification in H150 used EIGENVECTOR coordinates. In integer coordinates, w = 0 means c = 0 (the standard torroid component). The Perfect Square Theorem proves c = 0 is IMPOSSIBLE on the null cone. Therefore ALL 18 "constructive" roots and ALL 3 "existence" roots must have c ≥ 1.

What H150 measured as "w ≈ 0" actually means: the torroid EIGENVECTOR component of these roots is small but nonzero. The small w-component comes from c ≥ 1 combined with the 10⁻⁵ brace-box/torroid coupling (from H128).

The 21-Root Theorem's minimum word length 21 CANNOT come from the binary form (c = 0 slice). It must involve the full ternary form with c ≥ 1.

🧒 Toddler Version

Imagine trying to balance a seesaw PERFECTLY level using only whole bricks.

The seesaw tips one way if you put too many red bricks (brace) and the other way if you put too many blue bricks (box). The magic balance point needs 1.771... red bricks per blue brick. But you can only use WHOLE bricks!

You try 1 red + 1 blue = not balanced. You try 7 red + 4 blue = almost! You try 16 red + 9 blue = almost from the other side! Each try gets closer but NEVER reaches perfect balance. It's like a ball bouncing between two walls that never lets it stop in the middle.

The really big discovery: you CAN'T balance using JUST red and blue bricks. You NEED at least one purple brick (torroid) too. Without the purple brick, the seesaw will ALWAYS be tilted, no matter how many red and blue you use. That's because the magic number 1.771... can never be written as a simple fraction.

Known-Bad Control (KB-1)

The following claim is FALSE and must be detected as dead:

The continued fraction of n₊ is periodic with period 3, giving the repeating block [1, 3, 2]. This short period means the lattice can efficiently approximate n₊ and reach Q3p = 0 at moderate word length.

Why false: No period was detected in 35 terms. The CF partial quotients are irregular: 1, 3, 2, 1, 2, 4, 7, 2, 17, 11, 4, 14, 9, 35... The period (by Lagrange's theorem) is expected to be of order 10³²⁵. And even with perfect approximation, Q3p stays at ~325d (the elastic wall) — the lattice can NEVER reach Q3p = 0 in the c=0 plane.
