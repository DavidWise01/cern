Panel 3 — Cornacchia Blocked, Simon Available

Cornacchia's algorithm solves ax² + by² = n for POSITIVE DEFINITE forms. The descent form is indefinite, so Cornacchia is out.

However, polynomial-time algorithms DO exist for indefinite binary forms:

  ALGORITHM LANDSCAPE
  ═══════════════════
  Cornacchia:     positive definite only    ✗ (form is indefinite)
  Cont. fraction: works but O(√disc)        ✗ (period ~10^529)
  Simon (2005):   LLL-based, polynomial     ✓ in principle
  Cremona-Rusin:  modular symbols           ✓ in principle

  KEY: Simon's algorithm is polynomial in log(disc)
  For 1058-digit disc (~3513 bits): FEASIBLE in computation time

The algorithm exists and would run in reasonable time — IF we had the form's coefficients.
