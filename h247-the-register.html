Panel 4 — OCHO = Register Overflow

  3-bit register: addresses 0x00 through 0x07 (0 through 7).

  0x08 = 1000 in binary = needs BIT 4.
  0x08 = 8 = OCHO.

  OCHO is the FIRST ADDRESS THAT OVERFLOWS the 3-bit register.
  It's the carry bit. The boundary.

  Everything ≤ 0x07 fits in bodies bits.
  OCHO needs bodies+1 bits.

  OCHO = 2^bodies = the size of the address space.
  It is NOT an address IN the space — it's the COUNT of addresses.
  The number-of-addresses is not itself an address.
  The container is not contained.

I145: OCHO = 0x08 = 1000 = overflow of the 3-bit register. First address needing bit 4. [LIT]

Panel 7 — The Register Map

3-bit register. 8 addresses. Grade = popcount. Phantom = 0x07 = all bits set.

🧸 Toddler Version

Imagine a row of 3 light switches. Each can be ON or OFF.

OFF-OFF-OFF = 000 = address 0. All switches off. That's "nothing."

OFF-OFF-ON = 001 = address 1. One switch on.

OFF-ON-OFF = 010 = address 2 = d₁! That's the seed number!

ON-ON-ON = 111 = address 7 = the phantom! All switches ON!

There are 8 possible combinations (2×2×2). That's OCHO.

But address 8 would need a FOURTH switch. It OVERFLOWS — doesn't fit in 3 switches. That's why OCHO is special: it's the first number that's too big for the register.

The master number 336 = "how many ways to pick 3 addresses in order from these 8?" That's picking as many addresses as switches. The answer matches the question.
