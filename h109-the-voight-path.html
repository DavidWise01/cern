Panel 1 — The Hensel Breakthrough

Hensel lifting computes p-adic solutions to Q3_prim(v) = -1 WITHOUT factoring the determinant. This entirely bypasses the 1056-digit wall from H108.

How it works

Start with a solution mod p (found by brute force over the tiny field F_p). Lift iteratively: at each step, solve a LINEAR equation for the correction term using the gradient of the quadratic form. Each step extends the solution by one more p-adic digit.

  v₀ ≡ solution (mod p)        — brute force, O(p³)
  v₁ ≡ solution (mod p²)       — one gradient step
  v₂ ≡ solution (mod p³)       — one more step
  ...
  v_k ≡ solution (mod p^(k+1)) — k-th step

  Time per step: O(1) multiplications on big integers
  Total time for k=750 steps at p=3: 0.01 seconds

Panel 2 — The p-adic Extraction Gap

Hensel lifting gives coordinates that satisfy Q3_prim(v) ≡ -1 (mod p^k), but NOT Q3_prim(v) = -1 exactly. Three extraction methods attempted:

Method A: Single-prime centering

Lift at p=3 to k=400 (3^400 ≈ 10^191, well above the ~176-digit Minkowski bound). Center coordinates to [-3^400/2, 3^400/2]. Result:

  Standard lift:   coords (364, 1, 1) digits — DEGENERATE
  Balanced lift:   coords (191, 1, 191) digits — better but
  Centered Q3p(v): 787-digit number, NOT -1

The Hensel gradient follows the steepest descent, which grows only one coordinate. Even the "balanced" variant (picking the most compact delta at each step) produces degenerate shapes.

Method B: CRT combination

Lift at p=3 to k=765 and p=5 to k=526. Combine by Chinese Remainder Theorem. Result:

  CRT coords: (732, 732, 732) digits
  Q3p(v_CRT) mod M: ≡ -1 ✓  (M = 3^765 · 5^526)
  Q3p(v_CRT) exact:  NOT -1 (huge number)
  Centered: still NOT -1

Fundamental issue: the mod-3 and mod-5 lifts converge to DIFFERENT p-adic branches. CRT combines incompatible points on the solution surface.

Method C: Binary reduction

Fix z = t for t = 1,2,...,19. Complete the square to reduce to a binary form D₁₂·u² + w² = T.

  D₁₂ = ab - h² :  651 digits, NEGATIVE (form is indefinite ✓)
  T = E² - D₁₂·F:  1385-1388 digits, POSITIVE (solutions exist over R ✓)
  u bound:          ~10^367 (IMPOSSIBLE to enumerate)

The binary form IS indefinite (D₁₂ < 0) and T > 0 for every z tested, confirming real solutions exist. But the search space for u is 367 digits wide — no enumeration can reach it.

Panel 3 — The PARI Wall

Embedded Q3_prim(v) = -1 as a 4×4 isotropic vector problem:

  Q4(v₀,v₁,v₂,v₃) = v₀² + Q3_prim(v₁,v₂,v₃) = 0

  Signature (Q4): (2+, 2−) — indefinite, isotropic vectors exist
  PARI's qfsolve: designed for exactly this problem

Result: qfsolve TIMED OUT after 10 minutes. Internally, PARI's algorithm for 4-variable forms requires factoring the determinant — the same 1058-digit wall from H108, re-encountered from a different direction.

All three construction paths terminate at the same barrier: the determinant of Q3_prim cannot be factored with current technology.

Panel 4 — Why the Gap is Fundamental

The p-adic → integer extraction gap is not a computational limitation. It reflects the TOPOLOGY of the solution surface.

  Solution surface S: {v ∈ R³ : Q3_prim(v) = -1}

  S is a hyperboloid (signature 1+, 2−)
  S has two sheets (det < 0)

  Integer points on S: finitely many (by Minkowski)
  p-adic "sheets": exponentially many (branching at each lift step)

  Each prime sees its OWN projection of S:
    - p=3 sees S mod 3^k: a discrete set of ~3^(2k) points
    - p=5 sees S mod 5^j: a different discrete set
    - CRT combines: only valid if both projections come from
      the SAME integer point

The Hensel lift at each prime converges to a p-adic point that may not correspond to any integer point. The lift is LOCALLY correct (satisfies the congruence) but GLOBALLY inconsistent (no integer solution maps to all these p-adic points simultaneously via different primes).

To find the correct branch at each prime, you need to know WHICH integer solution you are lifting — which requires having the integer solution already. Circular.

Panel 7 — What Would Break the Wall

Five paths that could construct root 19 (none currently available):

  1. FACTOR det(Q3_prim)
     The 1056-digit cofactor. Needs quantum computer or
     mathematical breakthrough in NFS. Current record: 250 digits.

  2. LATTICE REDUCTION on the p-adic coset
     Build a lattice encoding the congruence constraints and
     use LLL/BKZ to find short vectors. Requires specialized
     implementation for ~300-digit lattice entries — beyond
     standard fpLLL capabilities.

  3. VOIGHT'S QUATERNION ORDER method
     Compute C₀(Q3_prim), find maximal order, extract norm form.
     Theoretically factoring-free, but requires a full quaternion
     algebra implementation that handles 300+ digit coefficients.

  4. FINCKE-POHST enumeration
     Enumerate short vectors in the quadratic form directly.
     Coordinate bound ~10^176, 3 dimensions: ~10^529 search space.
     Infeasible without massive lattice reduction first.

  5. MULTI-BRANCH p-adic exploration
     At a single prime, explore ALL p-adic branches (not just
     the gradient-steepest one) and check each for integer
     centering. Exponentially many branches at each step,
     but heuristically most can be pruned.

Toddler Version — The Three Tunnels

Remember the locked treasure room from H108? We know the treasure is IN there (the oracle told us in H107), but the key needs a 1056-digit number we cannot compute.

So we tried to DIG THREE TUNNELS around the door:

Tunnel 1 (Hensel): We found a magic mirror that shows what the treasure LOOKS LIKE from each direction. Looking through the red mirror shows one shape, the blue mirror another shape. Each mirror works perfectly! But when we try to put the shapes together to build the actual treasure... they do not fit. Each mirror showed a DIFFERENT treasure that happens to look the same from that angle.

Tunnel 2 (Binary): We found that if we guess one number right, the problem gets simpler — just find another number that makes it work. But the first number we have to guess is 367 digits long. Imagine trying every number from 1 to a number with 367 digits. If you tried one per second, the sun would burn out long, long before you finished.

Tunnel 3 (PARI): We asked a very smart math robot to solve it directly. The robot thought about it for 10 minutes and then said "I need to know that 1056-digit number too." It is the same locked door, seen from behind.

The treasure is real. We just cannot reach it yet. But we do not NEED to hold the treasure to know it is there — and knowing it is there is what tells us the magic word is exactly 21 letters long.
