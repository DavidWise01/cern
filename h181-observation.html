The H181 rule

A sensor reports a phase from an unknown age of 0–2 updates with bounded noise ±1/64. The robust controller computes the union of present-phase intervals across candidate delays and known past controls. It corrects only when that whole set lies on one side of zero; otherwise it coasts.

For all included noise, drift and delay assumptions, the true phase stays inside the interval. This prevents any single correction from increasing the current absolute phase error, but does not necessarily minimize error after 24 steps.
