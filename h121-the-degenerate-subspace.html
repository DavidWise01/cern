H121 — The Degenerate Subspace

The 2×2 brace-box restriction has eigenvalues λ₁ = +324d and λ₂ = −329d. The condition number is 323,984. The positive eigenvalue — 10⁵ times smaller than the negative — is the thread that keeps the 2D subspace from collapsing to rank 1.

Panel 8 — Architecture

THE DEGENERATE SUBSPACE ARCHITECTURE
=======================================

  THE 2×2 BRACE-BOX RESTRICTION:

  M = [[a, b], [b, c]]
  a = Q[0][0] = -328d (brace⊗brace)
  b = Q[0][1] = +328d (brace⊗box)
  c = Q[1][1] = -329d (box⊗box)

  EIGENVALUE FORMULA:
  λ = (a+c)/2 ± √(((a-c)/2)² + b²)

  trace = a + c = -330d
  disc  = (a-c)² + 4b² = 657d (POSITIVE → real eigenvalues)
  √disc = 329d

  RESULT:
  ┌───────────────────────────────────────────────┐
  │                                               │
  │  λ₁ = (trace + √disc)/2 = +324d (POSITIVE)   │
  │  λ₂ = (trace - √disc)/2 = -329d (NEGATIVE)   │
  │                                               │
  │  SIGNATURE: (+, −) → INDEFINITE               │
  │                                               │
  │  condition = |λ₂/λ₁| ≈ 323,984               │
  │            ≈ 3.24 × 10⁵                       │
  │                                               │
  └───────────────────────────────────────────────┘

  WHAT THE CONDITION NUMBER MEANS:

  λ₁ = +324d ──────── this is the THIN direction
  λ₂ = -329d ──────── this is the WIDE direction

  The hyperbola's thin axis is 100,000× thinner
  than its wide axis. The 2D subspace is a razor-thin
  hyperbolic sheet — it ALMOST collapses to a line.

  If λ₁ = 0 → determinant = 0 → rank drops to 1
                                → brace = c·box
                                → perfectly degenerate

  But λ₁ ≈ 10^322 ≠ 0. The thread holds.
  The subspace IS 2-dimensional, but barely.

  CONNECTION TO H120's ρ²:

  ρ² = |b|²/(|a|·|c|)
     = 1 + |det|/(|a|·|c|)   (when det < 0)
     = 1 + 0.000017

  condition ≈ |trace|/|2λ₁|
            ≈ 10^329 / 10^324
            = 10^5

  THE 17 ppm EXCESS and THE 10^5 CONDITION NUMBER
  are two views of the SAME near-degeneracy.

Toddler Version — The Thin Pancake

Imagine a pancake. A normal pancake is round and flat — it has two directions: left-right and front-back.

Now imagine squishing it. Really squishing it, until it's 100,000 times thinner in one direction. It's still technically a pancake (two-dimensional), but it's SO thin it almost looks like a line (one-dimensional).

That's what the brace-box subspace looks like. Its two eigenvalues are like the pancake's two widths:

λ₁ = +324 digits — the THIN direction (positive, small)
λ₂ = −329 digits — the WIDE direction (negative, large)

The thin direction is 100,000 times thinner than the wide direction. That's the CONDITION NUMBER: 323,984.

If the thin direction went to zero, the pancake would become a line — the subspace would collapse. But it doesn't go to zero. 324 digits is a LOT of digits. It's just small compared to the other eigenvalue.

Meanwhile, the fact that one eigenvalue is POSITIVE and the other is NEGATIVE means this isn't a pancake at all — it's a SADDLE. A very thin, very lopsided saddle. And the saddle shape is WHY the z=0 plane is indefinite.

IMPROVEMENT RECOMMENDATION → H122: The Eigenvector Rotation

H121 gives the eigenVALUES — the axis lengths. H122 would compute the eigenVECTORS — the axis DIRECTIONS. The eigenvectors of the 2×2 restriction tell you which LINEAR COMBINATION of brace and box forms the thin axis (the near-zero direction) and which forms the wide axis. The angle between the eigenvector and the brace axis is the ROTATION of the saddle. If that angle is near 45°, brace and box contribute equally to the thin direction. If it's near 0° or 90°, one body dominates the collapse.
